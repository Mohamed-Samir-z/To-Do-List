# 📝 Simple To-Do List Application

This is a simple, functional **To-Do List** application built with HTML, CSS, and JavaScript. This project is part of my journey to learn web development.

## 🚀 Features
* **Add Tasks:** Quickly add new tasks to your list.
* **Mark as Done:** Checkbox functionality to mark completed tasks (with sound effects 🔊).
* **Persistent Storage:** Uses `LocalStorage` to save your tasks so they don't disappear after refreshing the page.
* **Responsive Design:** Works on both desktop and mobile screens.

## 🛠️ Built With
* **HTML5** - For structure.
* **CSS3** - For styling and layout.
* **JavaScript (Vanilla)** - For logic and interactivity.

## 📁 Project Structure
* `index.html`: The main entry point.
* `style.css`: All the visual styling.
* `script.js`: Task management and sound logic.
* `Click.wav`: Local audio file for task completion.

## ⚖️ Security & Privacy
This is an **educational project**. No user data is collected or sent to any external servers. All task data remains locally on the user's browser via `LocalStorage`.
